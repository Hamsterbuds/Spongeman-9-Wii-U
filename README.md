# Spongeman 9 (Wii U Port)

> **Content Warning:** At certain points in this game, there are scenes that may be disturbing or upsetting to some players. Because this port is a faithful recreation of the original game, it includes the same dark humor and shock value from the 2020 executable.

A native C++/SDL2 recreation of the 2020 PC fangame **Spongeman 9**, built from the ground up to run at a locked 60fps on Wii U hardware via Aroma.

<img width="128" height="128" alt="iconTex" src="https://github.com/user-attachments/assets/428ea590-7e79-498b-8fa4-590bafede2b9" />

## Features
* Native PowerPC `.wuhb` execution at 60fps
* Full Wii U GamePad and Pro Controller support
* Faithful recreation of the original scenes, animations, and audio

## About
I created this because I've always found the game very different from other shitpost/surreal games. It has a sense of mid-2000s Flash games—with its heavily compressed audio, horribly animated sprites, and an overall bootleg feel that makes you start to think: *"Is this really a joke, or a real, cheap ripoff?"*

## SD Card Setup
Place the `.wuhb` and assets onto your Wii U SD card using the following layout:

```text
sd:/wiiu/apps/spongeman9/spongebob9.wuhb
sd:/wiiu/sm9/assets/game.dat
sd:/wiiu/sm9/assets/Images/
sd:/wiiu/sm9/assets/Audio/
sd:/wiiu/sm9/assets/tuning.txt
```
